# GeoGuardian Flutter Prototype

Prototipo de interfaz Flutter para GeoGuardian con diseño inspirado en la imagen proporcionada.

## Estructura
- `lib/main.dart`: aplicación principal y todas las pantallas UI.

## Ejecutar
1. Instala Flutter y configura tu entorno.
2. Abre una terminal en `app_flutter`.
3. Ejecuta:
   ```bash
   flutter pub get
   flutter run
   ```

## Notas
- Este proyecto es un prototipo de UI. Los datos mostrados son de ejemplo.
- Puedes extenderlo añadiendo lógica de autenticación, servicios de sensores y mapas reales.
