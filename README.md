# Proyecto-PICUR2026-2

## GeoGuardian AI

GeoGuardian AI es un proyecto orientado al monitoreo preventivo de zonas con riesgo geologico. La propuesta combina una aplicacion movil, sensores IoT, analisis con inteligencia artificial y material de documentacion para apoyar la deteccion temprana de condiciones de riesgo.

## Objetivo

Centralizar informacion de sensores, reportes y analisis visuales para ayudar a identificar cambios en el terreno, alertar a los usuarios y facilitar el seguimiento historico de eventos.

## Componentes del proyecto

- `app_flutter/`: aplicacion movil desarrollada en Flutter.
- `backend/`: espacio reservado para servicios, API y logica del servidor.
- `esp32/`: espacio reservado para firmware y configuracion de sensores IoT.
- `inteligencia_artificial/`: espacio reservado para modelos, prototipos o scripts de analisis.
- `documentacion/`: documentos tecnicos, guias y entregables del proyecto.
- `figma/`: recursos o enlaces relacionados con el diseno de interfaz.
- `maqueta/`: material de prototipado fisico o demostracion.
- `presentacion/`: diapositivas y material de exposicion.
- `recursos/`: imagenes, referencias y otros archivos de apoyo.

## Aplicacion Flutter

La app incluye pantallas para:

- Inicio de sesion y registro.
- Panel principal con estado de riesgo.
- Mapa de riesgo.
- Camara con enfoque de analisis IA.
- Historial de eventos.
- Alertas, perfil, seguridad y ajustes.

## Requisitos

- Flutter SDK instalado.
- Android Studio, Visual Studio Code u otro editor compatible.
- Un emulador o dispositivo fisico para ejecutar la app.

## Ejecucion local

```bash
cd app_flutter
flutter pub get
flutter run
```

## Estado

El repositorio contiene actualmente un prototipo funcional de interfaz en Flutter y la estructura base para integrar los demas componentes del sistema.
