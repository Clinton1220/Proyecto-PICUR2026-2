# Documentacion de GeoGuardian AI

Este directorio contiene la documentacion tecnica y funcional del proyecto
GeoGuardian AI.

GeoGuardian AI es una aplicacion orientada a la prevencion y monitoreo de
zonas con riesgo geologico. El prototipo actual combina una aplicacion movil
en Flutter, una estructura preparada para backend, una futura integracion con
sensores ESP32 y modulos de inteligencia artificial para apoyar el analisis de
riesgos.

## Alcance de esta documentacion

La documentacion refleja el estado actual del repositorio al 10 de agosto de
2026. En este momento la aplicacion Flutter funciona como prototipo de interfaz
y logica local; los directorios `backend`, `esp32` e
`inteligencia_artificial` estan preparados para futuras integraciones.
